# Terraform Assignment 1 – Deploy WordPress Using Terraform
### My Objectives

I will use Terraform to deploy a full WordPress stack on AWS.

My setup will include:

An EC2 instance running WordPress

Security groups

User data or cloud-init to install dependencies

A working public endpoint

All resources will be provisioned via Terraform

This assignment shows me how Terraform manages real infrastructure end-to-end.

### The Minimum Requirements
 
 A main.tf with AWS provider, EC2 resource and required settings

variables.tf for inputs

outputs.tf for instance details

User data script embedded or referenced
